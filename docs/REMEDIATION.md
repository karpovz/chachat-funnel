## Архитектура и удобство сопровождения

- Содержимое экранов и иллюстрация отделены от управления воронкой; checkout/recovery и navigation вынесены в hooks. Один shared definition задает порядок вопросов и допустимые ответы для UI и сервера.
- Ответы API проходят runtime-проверку Zod. Неожиданные серверные ошибки получают correlation ID и безопасную категорию без request body, email, card fields, exception message/stack/meta.
- Добавлены индексы истории сессий по пользователю/посетителю и времени. Unique/partial unique constraints и блокировки платежей сохранены. Конкурентное использование одного ключа разными сессиями дает 409 вместо случайного 500.
- Зафиксированы правила resume: абсолютные 90 дней cookies, сохранение исходной acquisition, повторное открытие оплаченной сессии на Install. Breaking quiz changes требуют отдельной политики миграции или перезапуска сессий перед выпуском.
- Добавлены работающие browser Back/Forward и защита прямого перехода на Install. Контраст затронутых текстов поднят выше 4,5:1. JSX, CSS, TypeScript и документы приведены к единому формату; CI проверяет его.
- Добавлен Docker dev-профиль с hot reload и БД на 127.0.0.1:15432. Установка при старте работает без диалога и сети из store образа, даже когда bind-mount находится на другой файловой системе. Изменение lockfile требует `up --build`.
- QA браузер использует настоящий localhost в сетевом пространстве приложения. Browser dependencies кешируются отдельным Docker-слоем; изменение исходников не требует повторного скачивания Chromium.
- Обновлены SPEC, AGENTS и AI_WORKFLOW: конкретные invariants, владение файлами, обязательные команды и единый запрет Git mutations для агентов. Дополнительные custom skills не добавлялись: для этой задачи достаточно инструкций и воспроизводимых команд.

Next.js App Router, strict TypeScript и PostgreSQL остаются основой проекта. Переход на другой ORM major не требовался для устранения дефектов; совместимость узкого security override проверяется отдельно.
